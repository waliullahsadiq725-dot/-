# د ننګرهار پوهنتون کتابتون

FastAPI + HTML/CSS/JavaScript. محصلین او استادان اکاونټ جوړوي، PDF کتابونه اپلوډ کوي، او نور یې لولي، لټوي او ډاونلوډ کوي.

## ځانګړتیاوې

**کارونکي**
- نوم لیکنه او ننوتل (محصل یا استاد)؛ پاسورډ په PBKDF2 ساتل کېږي
- پروفایل سمون او پاسورډ بدلول
- د ناسمو ننوتلو محدودیت (۸ هڅې په ۱۰ دقیقو کې)

**فایلونه**
- PDF اپلوډ د پرمختګ ښودنې، drag & drop او د PDF ریښتینولي ازموینې سره (تر 20MB)
- ۱۲ کټګورۍ (فکولټې)، لټون، ترتیب (نوي، ډېر ډاونلوډ، ډېر کتل شوي، سرلیک)، د پاڼو ویش
- په براوزر کې د PDF مخکتنه، ډاونلوډ، د ډاونلوډ او کتلو شمېرنه
- خوښې (bookmarks)، نظرونه، د فایل سمون او ړنګول
- «زما فایلونه» او «خوښې» برخې

**مدیر**
- احصایې او د کټګورۍ له مخې چارټ
- کارونکي: لټون، د ډول بدلول، مدیر کول، اکاونټ بندول/فعالول، د پاسورډ بیا ټاکل، ړنګول
- هر فایل او نظر ړنګولی شي

**ظاهر**
- روښانه/تیاره حالت، د موبایل لپاره ځانګړی ناوبري، RTL او پښتو

## په کمپیوټر کې چلول

```bash
pip install -r requirements.txt
ADMIN_EMAIL=you@example.com uvicorn main:app --reload
```

بیا پرانیزئ: http://127.0.0.1:8000 — د `ADMIN_EMAIL` په ایمیل اکاونټ جوړ کړئ، هغه مدیر کېږي.

## په Render کې لایف کول

1. دا فولډر په GitHub کې نوي repository ته اپلوډ کړئ.
2. په Render کې **New → Blueprint** وټاکئ؛ `render.yaml` ټول تنظیمات پخپله اخلي.
   (یا **New → Web Service**:
   Build: `pip install -r requirements.txt`
   Start: `uvicorn main:app --host 0.0.0.0 --port $PORT`)
3. Environment Variables:
   - `ADMIN_EMAIL` — د مدیر ایمیل (څو ایمیلونه په کوما سره)
   - `DATA_DIR=/var/data` — د Disk لپاره
4. **Disk** اضافه کړئ (Mount Path: `/var/data`).

### مهم
د Render وړیا (Free) پلان فایل سیسټم لنډمهاله دی: هر ځل چې سرویس بیا پیلېږي یا نوی ډیپلوی کېږي، ډیټابیس او اپلوډ شوي PDF ړنګېږي.
د دایمي ساتلو لپاره Disk لرونکی پلان (Starter) وکاروئ.
په یو سرور کې SQLite کافي ده؛ که ډېر کارونکي شي، PostgreSQL ته بدلول غوره دي.
